BEFORE WE BECOME MEMORIES — WEBSITE
===================================

Ini versi website yang disesuaikan dengan PDF buku Canva kamu. Semua 11 halaman PDF dirender menjadi gambar berkualitas tinggi dan disertakan di folder assets, jadi desain, tulisan, dan foto di buku tetap terlihat seperti versi Canva aslinya.

CARA MEMBUKA DI VS CODE
1. Ekstrak file ZIP ke folder yang kamu inginkan.
2. Buka VS Code > File > Open Folder, lalu pilih folder six-years-and-a-little-more.
3. Klik kanan index.html > Open with Live Server (jika ekstensi Live Server sudah terpasang), atau buka index.html langsung di browser.
4. Tekan tombol “Buka buku kecil kita”, lalu gunakan tombol Sebelumnya/Berikutnya atau thumbnail untuk membaca 11 halaman.
5. Klik gambar halaman untuk memperbesar.

MUSIK OPSIONAL
- Masukkan file audio yang kamu punya izin untuk digunakan ke folder assets.
- Namai file tersebut music.mp3.
- Tombol musik di website akan memutar dan menjeda audio.
- Website tetap berjalan walau tidak ada musik.

MENGUBAH ISI
- Teks website utama ada di index.html.
- Tampilan ada di style.css.
- Tombol dan navigasi halaman ada di script.js.
- Gambar halaman asli ada di assets/page-01.jpg sampai assets/page-11.jpg. Jangan menghapus atau mengganti nama file tersebut jika tidak ikut mengubah referensinya di kode.

MEMBUAT LINK PUBLIK DENGAN GITHUB PAGES
1. Buat repository baru di GitHub.
2. Upload seluruh ISI folder ini (index.html, style.css, script.js, README.txt, dan folder assets) ke repository. Jangan hanya upload file ZIP.
3. Buka Settings > Pages.
4. Pada bagian Build and deployment, pilih Deploy from a branch.
5. Pilih branch main dan folder /(root), lalu Save.
6. Tunggu proses publikasi selesai. GitHub akan menampilkan URL website kamu.

CATATAN PRIVASI
Jika website dipublikasikan, siapa pun yang memiliki link dapat melihat isi buku dan foto yang ditampilkan. Pastikan kamu nyaman membagikan foto dan cerita di dalamnya.
